# Visual Story Windows installation (English)

The project includes two `.bat.txt` installer-related scripts. They are stored as text to support upload/download systems. **Review the contents before running**. The installer has not yet been tested on Windows hardware.

1. Download the Visual-Story repository and unzip it.
2. Locate `community/install/PC_install.bat.txt` and `community/install/PC_rename.bat.txt`.
3. Follow the original [Traditional Chinese install notes](安裝說明.txt), or manually copy the **entire** `community/` directory to `%USERPROFILE%\.codex\skills\visual-story-site` (use `%CODEX_HOME%\skills\visual-story-site` if set).
4. Restart Codex and reference `$visual-story-site`.

The browser demo is independent of Codex: open `community/assets/starter-site/index.html` and use the language selector.
