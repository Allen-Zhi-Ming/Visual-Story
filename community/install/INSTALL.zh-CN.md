# Visual Story Windows 安装说明（简体中文）

仓库提供 `PC_install.bat.txt` 与 `PC_rename.bat.txt` 两个安装脚本。它们以 `.txt` 形式保存，**执行前请先检查内容**。本次尚未在 Windows 设备上实测。

1. 下载并解压 Visual-Story。
2. 找到 `community/install/` 目录，按照[原始安装说明](安裝說明.txt)操作；或直接将完整 `community/` 文件夹复制至 `%USERPROFILE%\.codex\skills\visual-story-site`，如有 `CODEX_HOME` 则使用其中 `skills` 目录。
3. 重启 Codex，输入 `$visual-story-site`。

演示网站可以独立打开 `community/assets/starter-site/index.html`，用顶部语言菜单切换。
