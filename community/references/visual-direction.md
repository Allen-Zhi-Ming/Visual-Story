# 視覺方向與角色一致性

## 角色不變錨點（Character Lock）

記錄正面、側面、背面、臉部特寫和材質細節；至少固定：臉部骨架、眼睛主色、髮型與分線、頭飾、主衣著剪裁、配件形狀、鞋型、主要／輔助配色、視覺筆觸與比例。已有正式角色／產品設計時，不得根據「更美」自行改款。

每個延伸場景採用三層提示：

- **固定層**：角色完整外觀規格、同一素材來源與禁止變化清單。
- **可變層**：動作、情緒、環境、鏡頭、時間、光線、構圖。
- **輸出層**：比例、文字安全區、解析度目標、透明／不透明背景、用途。

對每張生成圖與原設定對照：五官、髮型、衣著、配件、手指／肢體、材質細節與色彩，記錄 `PASS / REWORK / NOT_REVIEWED`；不把單張樣圖當作所有角度都通過。

## 品牌視覺決策

- 可選一種核心感受（例如：未來 × 個性 × 親近），再建立約 3–5 個可檢查的視覺規則。
- 設計語法：主色／強調色／背景色、展示字級與正文的對比、卡片圓角、分隔節奏、陰影、材質、空白與對齊。
- 參考站只記「資訊架構／字體節奏／區段切換／動效原理／留白策略」，保留來源 URL 和權利備註；不要整頁重製。
- 主視覺重要區域預留文案與按鈕；手機裁切不可把臉、商品輪廓或關鍵文字切掉。

## 可交付的 Style Contract

```
品牌／角色名稱、用途、受眾
角色錨點：固定項目與允許變更的項目
色彩 token：背景、前景、品牌、次色、警示
字級與格線：手機／桌面
場景列表：用途、焦點、景別、輸出比例、素材狀態
禁止事項：未授權素材、角色漂移、虛構展示內容
```
