# 视觉方向与角色一致性

## 角色固定设定（Character Lock）

记录正面、侧面、背面、脸部特写和材质细节；固定脸部结构、眼睛主色、发型与分线、头饰、服饰剪裁、配件、鞋型、配色、视觉风格与比例。对于已确定的角色／商品，不得以“更美”为由擅自改款。

每个场景包含三个层次：

- **固定层：** 完整角色外观、来源素材、禁止变化清单。
- **可变层：** 动作、情绪、环境、镜头、时间、光线、构图。
- **输出层：** 宽高比、文字安全区、分辨率、透明背景及用途。

逐图对比五官、发型、服饰、配件、手指与肢体、材质和颜色，并记录 `PASS / REWORK / NOT_REVIEWED`；单张正面图通过不代表所有视角通过。

## 品牌视觉决策

- 选择核心感受（例如未来 × 个性 × 亲近），建立约 3–5 条可检查的视觉规则。
- 设定主色、强调色、背景色、标题和正文层级、圆角、区段节奏、阴影、材质、留白与对齐。
- 参考网站只提取信息架构、字体节奏、转场原则和留白策略，保留来源链接与权利说明；不要整页复制。
- 主视觉须为标题与 CTA 留足空间，移动端裁切不能遮挡角色面部、商品轮廓或关键信息。

## Style Contract

```
品牌／角色、用途、受众
角色设定：固定与允许变化项目
配色：背景、前景、主色、强调色、警示色
字体与网格：移动端／桌面
场景：用途、焦点、景别、比例、素材状态
禁止事项：未授权素材、角色偏移、虚构成果
```
