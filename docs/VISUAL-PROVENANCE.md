# Visual Story v1.3 · imagery provenance and limitations

- `media/echo-editorial.webp` — original generative editorial portrait created for this redesign; fictional fashion concept.
- `media/vale-editorial.webp` — original generated fashion concept image, cropped from our generated website concept illustration.
- `media/aura-product.webp` — original generated technical jacket concept, cropped from our generated website concept illustration.
- All people, goods, labels and prices are conceptual examples, not authenticated third-party brands or physical products. Images are not evidence of real inventory, physical garment properties, character generation capability or real customers.
- Switching Echo scene/pose is a CSS treatment of the same portrait. Switching Vale collection is a color treatment of the same photograph. Switching Aura color is an illustrative rendering treatment, not a verified SKU/colorway.
- There are no external image CDNs at runtime. These images ship locally with the public demo.
- No licensing terms are changed.
